step to deploy the application

In W:\Extensions\website, run:

npm.cmd install
npm.cmd run build
npm.cmd test
npm.cmd run seo:check
git status --short

Review the changed and untracked files, then commit the website files and push them to GitHub. Check the remote before pushing: this checkout currently points to https://github.com/Dharmareddy8520/AdNinja-.git. Confirm that this is the repository where you want the website published. Cloudflare deploys the committed files, so local uncommitted changes will not appear on the site.

### 2. Create the Cloudflare Pages project

1. Open the Cloudflare dashboard (https://dash.cloudflare.com/) → Workers & Pages → Create application.
2. Choose Pages → Import an existing Git repository.
3. Connect GitHub and select the repository containing this website.
4. Set Production branch to main and Root directory to / if the repository root is this website.
5. Select Next.js (Static HTML Export). Use:
   - Build command: npm run build
   - Build output directory: out
6. Start the deployment. Cloudflare will provide a *.pages.dev address. These settings match Cloudflare’s static Next.js guide (https://developers.cloudflare.com/pages/framework-guides/nextjs/deploy-a-static-nextjs-site/).

### 3. Keep indexing off for the first deployment

The site currently defaults to noindex. Leave SEO_INDEXING_ENABLED unset or set it to false while you check the public site. Open the homepage, /features, /support, /robots.txt, /sitemap.xml, and /social-preview.png. Check the mobile layout and dark-mode toggle too.

### 4. Add your final domain and enable SEO when ready

In the Pages project, go to Custom domains → Set up a domain and follow Cloudflare’s DNS instructions. An apex domain may require moving its nameservers to Cloudflare; a subdomain can use a CNAME. Cloudflare custom-domain instructions (https://developers.cloudflare.com/pages/configuration/custom-domains/)

Once the domain and legal content are approved, set these Production build environment variables in the Pages project:

SITE_URL=https://your-final-domain
SEO_INDEXING_ENABLED=true

Use your real HTTPS domain, with no trailing slash. Keep SEO_INDEXING_ENABLED=false for Preview builds, then redeploy production and check its canonical URLs, robots.txt, and sitemap.xml. Cloudflare lets you configure build variables in the Pages project settings. Build configuration (https://developers.cloudflare.com/pages/configuration/build-configuration/)

Do not enable indexing yet if the privacy policy, publisher details, or licensing still need approval. No deployment has been made from this checkout.
